# Third-party notices for this task

Attribution and licence notices for third-party material redistributed in this task.
This file is intentionally placed beside `task.toml`, outside `environment/source/env/`,
so that it travels with the distribution without becoming visible to the model under
evaluation.

## 1000 Genomes Project data

The grading path derives one reviewed cohort from the **1000 Genomes Project** phase-3 GRCh37
chromosome-22 genotype callset and sample panel, hosted by the International Genome Sample
Resource (IGSR). The callset and panel are **fetched at image-build time** — by
`tasks/from_scratch_pca/tests/Dockerfile` for the packaged verifier image and by
`environment/provision.sh` for the Hyperfocal path — with byte count and SHA-256 asserted before
use, and deleted after derivation. Sample identifiers in the derived cohort are replaced with
HMAC-derived aliases.

Cite: The 1000 Genomes Project Consortium, "A global reference for human genetic variation",
Nature 526, 68–74 (2015). IGSR publishes the phase-3 data for use without restriction, so no
redistribution licence attaches to it.

### What this repository actually redistributes

`environment/source/env/docs/figs/chr22_pca/` ships four real-data artifacts used to render the
documentation figures:

| File | Content |
|---|---|
| `panel.txt` | the official 1000 Genomes sample panel, byte-identical to upstream: 2,504 individuals with population, super-population and gender |
| `ours.tsv`, `anchor.tsv` | PC1-PC10 per sample, keyed by 1000 Genomes sample ID |
| `plink2.tsv` | the same, computed by PLINK 2.0 |

No genotype callset bytes ship; the 205 MB source VCF is never redistributed.

## SauersML authorship

`environment/source/env/tasks/from_scratch_pca/task.toml` records this benchmark's author as
**SauersML**. See `LICENSING.md` for the written-grant position covering SauersML-authored
material in this delivery.

`environment/source/env/docs/source_evaluation_audit.md` records that two SauersML repositories
were **reviewed but not copied**: `SauersML/efficient_pca` (MIT, root licence present) and
`SauersML/genomic_pca` (no root licence file; its bundled population tables and chromosome-22
archives were judged to lack clear per-file redistribution provenance). Only general testing ideas
were reimplemented; **no source, test code or data was copied from either**.

## PLINK

`docs/figs/chr22_pca/plink2.tsv` and the comparison tables in `docs/benchmark_vs_tools.md` were
produced by running **PLINK 2.0** (GPL-3.0). No PLINK source or binary is redistributed, and
copyleft does not attach to a program's output, so this is recorded for completeness rather than
as an obligation.

## Everything else

All other cohorts are synthetic, generated by `environment/source/env/data/generate.py`
(Balding-Nichols model with planted structure). The runtime is NumPy and SciPy only; the
`cheats/sklearn_pca` fixture imports scikit-learn (BSD-3-Clause) but is an anti-cheat probe that
the task image never installs. No third-party library is vendored, and no model weights ship.
