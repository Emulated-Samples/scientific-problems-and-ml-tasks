# Third-party notices for this task

Attribution and licence notices for third-party material redistributed in this task.
This file is intentionally placed beside `task.toml`, outside `environment/source/env/`,
so that it travels with the distribution without becoming visible to the model under
evaluation.

## lat (MIT)

The `workspace/` tree of this task is the **lat** library ("Linearized Attribution Tracer"),
**Copyright (c) 2026 Ryan "RyanIRL" Peters**, MIT licensed. Full text at `LICENSES/MIT-lat.txt`;
the in-tree copy is `environment/source/env/workspace/LICENSE`.

**Modifications:** the source has been modified by Emulated for this evaluation environment — the
fast backward-sweep path is withheld from the agent's branch and restored by
`solution/solution.patch`.

the only copyright notice anywhere in the tree is the one above.

published algorithm; no upstream code is copied.

## Derived circuit fixture

`workspace/tests/fixtures/circuits/capital_of_france.json` (and its copy under
`environment/behavioral-tests/fixtures/`) is a ~15 KB attribution graph — 16 nodes and 45 edge
weights — whose own metadata records that it was **generated by circuit-tracer** running on
Qwen3-4B (Apache-2.0) with the third-party transcoders at `mwhanna/qwen3-4b-transcoders`.

> **Noted, low materiality:** it is model-derived numeric output rather than copied content, and
> the transcoder repository's terms are not recorded in the tree. If the buyer's policy treats
> model-derived artifacts as licensable material, this is the one file in this task that would be
> in scope.
